שאלה 1 25 נק' — סיבוכיות

לכל סעיף ציינו סיבוכיות זמן וסיבוכיות מקום נוסף, בסימון Θ, כפונקציה של n. חובה לפשט את הביטוי ככל שניתן. הניחו כי סיבוכיות הזמן והמקום של printf ו-free היא Θ(1), וכי סיבוכיות הזמן של malloc(n) היא Θ(1) וסיבוכיות המקום שלה היא Θ(n).

שימו לב: אין הבטחה ששלושת הסעיפים מקבלים תשובות שונות. חשבו כל סעיף מחדש, ובפרט שימו לב מתי משוחרר הזיכרון ביחס לקריאה הרקורסיבית.

א.

void f1(int n) {
    for (int i = n; i > 1; i /= 2) {
        for (int j = 0; j < i; j++) {
            printf("*");
        }
    }
}

ב.

int f2(int n) {
    if (n <= 1) return 1;
    int* arr = (int*) malloc(n * sizeof(int));
    if (arr == NULL) return 0;
    for (int i = 0; i < n; i++) {
        arr[i] = i;
    }
    int res = f2(n / 2);
    free(arr);
    return res;
}

ג.

int f3(int n) {
    if (n <= 1) return 1;
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    return f3(n / 2);
}

שאלה 2 25 נק'

נתון מערך arr של מספרים שלמים, ממוין בסדר לא-יורד, שאורכו אינו נתון לכם. סוף הנתונים מסומן על ידי הערך המיוחד EMPTY (המוגדר בשלד כ-INT_MIN): כל תא מהאינדקס n והלאה מכיל EMPTY, ואף איבר אמיתי אינו שווה ל-EMPTY.

ניתן לקרוא בבטחה מכל אינדקס שהוא חזקה של 2, וכן מכל אינדקס קטן ממנו.

int examT_q2(int* arr, int x);

על הפונקציה להחזיר את האינדקס שבו מופיע x, או -1 אם x אינו במערך. אם x מופיע יותר מפעם אחת, ניתן להחזיר כל אחד מהאינדקסים שלו.

קלטפלטהסבר
arr = {1,3,5,7,9,11,13,EMPTY,...}, x = 73arr[3] = 7
arr = {1,3,5,7,9,11,13,EMPTY,...}, x = 8-18 אינו במערך
arr = {5,EMPTY,...}, x = 50מערך באורך 1
arr = {EMPTY,...}, x = 1-1מערך ריק
  • סמנו ב-n את מספר האיברים האמיתיים במערך. הסיבוכיות נמדדת כפונקציה של n.
  • אין לשנות את תוכן המערך ואין להקצות זיכרון דינמי.
  • שימו לב: סריקה לינארית כדי למצוא את אורך המערך אינה עומדת בדרישת הסיבוכיות.
דרישות סיבוכיותזמן Θ(log n)מקום נוסף Θ(1)

שאלה 3 25 נק'

נתונה מחרוזת s באורך n המכילה אותיות אנגליות קטנות בלבד.

int examT_q3(char* s);

על הפונקציה להחזיר את האינדקס של התו הראשון ב-s שאינו חוזר על עצמו באף מקום אחר במחרוזת, או -1 אם כל תו מופיע יותר מפעם אחת.

קלטפלטהסבר
s = "leetcode"0'l' מופיע פעם אחת
s = "loveleetcode"2'v' — 'l','o' חוזרים
s = "aabb"-1כל תו חוזר
s = "swiss"1'w'
  • אין לשנות את תוכן המחרוזת s, אפילו לא באופן זמני.
  • מותר מעבר יחיד בלבד על s. עבודה על מערך בגודל קבוע (26 תאים) אינה נחשבת מעבר על המחרוזת.
  • ניתן להניח כי הקלט תקין וכי s אינה ריקה.
דרישות סיבוכיותזמן Θ(n)מקום נוסף Θ(1)

שאלה 4 25 נק' — רקורסיה

נתונות שתי מחרוזות a ו-b המכילות אותיות אנגליות קטנות בלבד.

נאמר ש-b מכילה את a אם כל תו מופיע ב-b לפחות כמספר הפעמים שהוא מופיע ב-a. הסדר אינו משנה.

int examT_q4(char* a, char* b);

על הפונקציה להחזיר 1 אם b מכילה את a, ו-0 אחרת.

קלטפלטהסבר
a = "abc", b = "cba"1אותם תווים
a = "aab", b = "ab"0ב-b יש רק 'a' אחד
a = "ab", b = "aab"1יש מספיק מכל תו
a = "zzz", b = "zz"0חסר 'z' אחד
  • על הפונקציה להיות רקורסיבית בלבד, ללא שימוש בלולאות — בכל הפונקציות שתכתבו.
  • אסור להשתמש בפונקציית מעטפת — examT_q4 עצמה חייבת לקרוא לעצמה.
  • ניתן להשתמש בפונקציות עזר, יש לממש את כולן, וגם הן חייבות להיות רקורסיביות בלבד.
  • אין להקצות זיכרון דינמי, אין להשתמש במערכים ואין לשנות את המחרוזות.
  • אין דרישות סיבוכיות בשאלה זו.

איך עובדים כאן

  • כתבו בעורך שמשמאל. שלושה קבצים, לשונית לכל שאלה. אל תשנו את main.
  • הרץ בדיקות מריץ את הפונקציה שלכם מול מקרי הבדיקה של השאלה — כולל בדיקות של האילוצים (לולאות ברקורסיה, שינוי הקלט, פונקציית מעטפת).
  • סיבוכיות אינה נבדקת אוטומטית. פתרון שעובר את כל הבדיקות בסיבוכיות שגויה — נכשל בשאלה.
