שאלה 1 — ניתוח סיבוכיות

לכל קטע קוד בחרו את סיבוכיות הזמן והמקום ההדוקות ביותר.

א

void triangle(int n) {
    for (int remaining = n; remaining > 0; remaining--)
        for (int j = 0; j < remaining; j++)
            putchar('.');
}

ב

int halves(int n) {
    if (n <= 1) return 1;
    return halves(n / 2) + halves(n / 2);
}

ג

void levels(int n) {
    for (int i = 1; i < n; i *= 2)
        for (int j = 0; j < 16; j++)
            putchar('.');
}

שאלה 2 — ספירת מופעים במערך ממוין

המערך ממוין בסדר עולה ועשוי להכיל כפילויות. החזירו כמה פעמים x מופיע בו.

int examT_q2(int arr[], int n, int x);

דוגמה: עבור {1,2,2,2,3,4} ו־x=2 מוחזר 3; עבור x=5 מוחזר 0.

דרישות: זמן Θ(log n), מקום נוסף Θ(1); אין לבצע סריקה ליניארית.

שאלה 3 — תתי־מחרוזות עם שכיחות חסומה

ספרו את כל תתי־המחרוזות הלא־ריקות שבהן מספר ההופעות של התו השכיח ביותר אינו עולה על k. אין לשנות את המחרוזת.

int examT_q3(char *s, int k);

דוגמה: עבור "aab" ו־k=1 מוחזר 4.

דרישות: זמן O(n²), מקום נוסף O(1).

שאלה 4 — קידומת משותפת ארוכה ביותר

החזירו את אורך הקידומת המשותפת הארוכה ביותר של שתי המחרוזות.

int examT_q4(char *a, char *b);

דוגמה: עבור "flower" ו־"flow" מוחזר 4; עבור "dog" ו־"cat" מוחזר 0.

הפונקציה עצמה חייבת להיות רקורסיבית; אין פונקציית מעטפת ואין לולאות.
