שאלה 1 — ניתוח סיבוכיות

לכל קטע קוד בחרו את סיבוכיות הזמן והמקום ההדוקות ביותר.

א

void half(int n) {
    if (n <= 1) return;
    half(n / 2);
}

void down(int n) {
    if (n <= 1) return;
    down(n - 1);
}

void both(int n) {
    half(n);
    down(n);
}

ב

void levels(int n) {
    for (int i = 1; i < n; i *= 2)
        for (int j = 0; j < 12; j++)
            putchar('.');
}

ג

void shrinking(int n) {
    for (int left = n; left > 0; left--)
        for (int j = 0; j < left; j++)
            putchar('.');
}

שאלה 2 — חיפוש דוהר באורך לא ידוע

המערך ממוין ומסתיים בזקיף INT_MIN; אורכו האמיתי אינו נתון. החזירו את האינדקס של x, או ‎-1.

int examT_q2(int arr[], int x);

דוגמה: עבור {1,3,5,7,9,INT_MIN,...} ו־x=7 מוחזר 3.

דרישות: מצאו חסם עליון בהכפלה ולאחר מכן בצעו חיפוש בינארי; זמן Θ(log n), מקום Θ(1).

שאלה 3 — נקודת איזון של קבוצות תווים

מצאו את האינדקס הקטן ביותר i שבו קבוצת התווים השונים בקידומת s[0..i] שווה לקבוצת התווים השונים בסיומת שאחריה. אין לשנות את המחרוזת.

int examT_q3(char *s);

דוגמה: עבור "abcabc" מוחזר 2.

דרישות: מסכת נוכחות של 26 ביטים, זמן Θ(n), מקום נוסף Θ(1).

שאלה 4 — תתי־סדרות שסכומן k

ספרו תתי־סדרות (בחירת קבוצה כלשהי של איברים, לא בהכרח רציפים) שסכומן בדיוק k.

int examT_q4(int *arr, int n, int k);

דוגמה: עבור {1,2,3} ו־k=3 מוחזר 2.

הפונקציה עצמה חייבת לבצע רקורסיית כלול/אל־תכלול; אין מעטפת ואין לולאות.
