שאלה 1 — ניתוח סיבוכיות

בחרו את סיבוכיות הזמן והמקום ההדוקות ביותר.

א

void layered(int n) {
    for (int i = 1; i < n; i *= 2)
        for (int j = 0; j < n / i; j++)
            for (int k = 0; k < i; k++)
                putchar('.');
}

ב

void shrinking(int n) {
    for (int left = n; left > 0; left--)
        for (int j = 0; j < left; j++)
            putchar('.');
}

ג

void half(int n) {
    if (n <= 1) return;
    half(n / 2);
}
void down(int n) {
    if (n <= 1) return;
    down(n - 1);
}
void both(int n) {
    half(n);
    down(n);
}

שאלה 2 — חיפוש מדרגות במטריצה

כל שורה וכל עמודה ממוינות בסדר עולה. החזירו 1 אם x נמצא, אחרת 0.

#define N 3
int examT_q2(int mat[][N], int m, int x);

דוגמה: במטריצה ששורותיה {1,4,7},{2,5,8},{3,6,9}, עבור x=6 מוחזר 1.

דרישות: התחילו בפינה הימנית העליונה; זמן O(m+N), מקום O(1).
