שאלה 1 25 נק' — סיבוכיות

לכל סעיף ציינו סיבוכיות זמן וסיבוכיות מקום נוסף, בסימון Θ, כפונקציה של n. חובה לפשט את הביטוי ככל שניתן. הניחו כי סיבוכיות הזמן והמקום של printf ו-free היא Θ(1), וכי סיבוכיות הזמן של malloc(n) היא Θ(1) וסיבוכיות המקום שלה היא Θ(n).

א.

void f1(int n) {
    for (int i = 1; i * i < n; i++) {
        printf("*");
    }
}

ב.

int f2(int n) {
    if (n <= 1) return 1;
    return f2(n / 2) + f2(n / 2);
}

ג.

void f3(int n) {
    for (int i = 2; i < n; i = i * i) {
        printf("*");
    }
}

שאלה 2 25 נק'

נתון מערך arr באורך n של מספרים שלמים אי-שליליים, ומספר שלם D המקיים 1 ≤ D ≤ n.

יש לחלק את המערך, לפי הסדר, ל-D קבוצות רציפות ולא ריקות בדיוק. עלות החלוקה היא סכום האיברים של הקבוצה שסכומה הגדול ביותר.

int examT_q2(int arr[], int n, int D);

על הפונקציה להחזיר את העלות המינימלית האפשרית על פני כל החלוקות החוקיות.

arr = {7,2,5,10,8}, n = 5, D = 218{7,2,5} ו-{10,8}
arr = {1,2,3,4,5}, n = 5, D = 29{1,2,3} ו-{4,5}
arr = {1,...,10}, n = 10, D = 515—
arr = {3,3,3,3,3}, n = 5, D = 115קבוצה אחת בלבד

  • אין לשנות את תוכן המערך ואין להקצות זיכרון דינמי.
  • סמנו ב-S את סכום כל איברי המערך.

שאלה 3 25 נק'

נתונה מחרוזת s באורך n המכילה אותיות אנגליות קטנות ותווי '$' בלבד.

מילה היא רצף רציף ומקסימלי של אותיות. רווח הוא רצף רציף ומקסימלי של תווי '$'.

יש להחליף כל רווח בתו בודד, לפי הכלל הבא: אם אורך הרווח גדול ממש מאורך המילה שמופיעה מיד לפניו — יש להחליפו ב-'+'; אחרת — ב-'*'. רווח שמופיע בתחילת המחרוזת נחשב כאילו אורך המילה שלפניו הוא 0.

int examT_q3(char* s);

על הפונקציה לבצע את ההחלפות במקום, בתוך s עצמה (תוך הזזת שאר התווים שמאלה וסיום המחרוזת ב-'\0'), ולהחזיר את מספר הרווחים שהוחלפו ב-'+'.

קלטפלטs לאחר הקריאה
s = "ab$$$cd"1"ab+cd"  (3 > 2)
s = "ab$cd"0"ab*cd"  (1 ≤ 2)
s = "a$$b$c"1"a+b*c"
s = "$a$$b$$$"3"+a+b+"
  • ניתן להניח כי הקלט תקין וכי s אינה ריקה.
  • אין להקצות זיכרון דינמי ואין להשתמש במערך עזר.
  • אין להשתמש בפונקציות ספריה לטיפול במחרוזות.
  • שימו לב: אורך המילה הרלוונטי הוא של המילה שלפני הרווח, ולא שאחריו.
דרישות סיבוכיותזמן Θ(n)מקום נוסף Θ(1)

שאלה 4 25 נק' — רקורסיה

נתונים שני מספרים שלמים וחיוביים n ו-k.

נאמר ש-n הוא k-חלק אם כל הגורמים הראשוניים של n קטנים או שווים ל-k. המספר 1 הוא k-חלק עבור כל k (אין לו גורמים ראשוניים).

int examT_q4(int n, int k);

על הפונקציה להחזיר 1 אם n הוא k-חלק, ו-0 אחרת.

קלטפלטהסבר
n = 12, k = 3112 = 2·2·3
n = 14, k = 3014 = 2·7 והגורם 7 גדול מ-3
n = 100, k = 51100 = 2·2·5·5
n = 1, k = 11אין גורמים ראשוניים
  • על הפונקציה להיות רקורסיבית בלבד, ללא שימוש בלולאות.
  • אסור להשתמש בפונקציית מעטפת — examT_q4 חייבת בעצמה להיות רקורסיבית.
  • ניתן להשתמש בפונקציות עזר, יש לממש את כולן, וגם הן חייבות להיות רקורסיביות בלבד.
  • אין להקצות זיכרון דינמי ואין להשתמש בפונקציות ספריה מתמטיות.
  • אין דרישות סיבוכיות בשאלה זו.

איך עובדים כאן

  • כתבו בעורך שמשמאל. שלושה קבצים, לשונית לכל שאלה. אל תשנו את main.
  • הרץ בדיקות מריץ את הפונקציה שלכם מול מקרי הבדיקה של השאלה — כולל בדיקות של האילוצים (לולאות ברקורסיה, שינוי הקלט, פונקציית מעטפת).
  • סיבוכיות אינה נבדקת אוטומטית. פתרון שעובר את כל הבדיקות בסיבוכיות שגויה — נכשל בשאלה.
