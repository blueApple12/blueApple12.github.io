שאלה 1 25 נק' — סיבוכיות

לכל סעיף ציינו סיבוכיות זמן וסיבוכיות מקום נוסף, בסימון Θ, כפונקציה של n. חובה לפשט את הביטוי ככל שניתן. הניחו כי סיבוכיות הזמן והמקום של printf ו-free היא Θ(1), וכי סיבוכיות הזמן של malloc(n) היא Θ(1) וסיבוכיות המקום שלה היא Θ(n).

א.

void f1(int n) {
    int i = 1;
    while (i * i <= n) {
        printf("*");
        i++;
    }
}

ב.

int f2(int n) {
    if (n <= 1) return 1;
    for (int i = 0; i < n; i++) {
        printf("*");
    }
    return f2(n / 2);
}

ג.

int f3(int n) {
    if (n <= 1) return 1;
    int* arr = (int*) malloc(n * sizeof(int));
    if (arr == NULL) return 0;
    for (int i = 0; i < n; i++) {
        arr[i] = i;
    }
    free(arr);
    return f3(n - 1);
}

שאלה 2 25 נק'

הגדרה: מערך arr באורך n ייקרא מערך הררי אם קיים אינדקס p, כאשר 0 < p < n-1, כך ש-

  • arr[0] < arr[1] < ... < arr[p]  (עולה ממש עד p), וגם
  • arr[p] > arr[p+1] > ... > arr[n-1]  (יורד ממש מ-p והלאה)
int examT_q2(int arr[], int n);

על הפונקציה להחזיר את האינדקס p של השיא — האיבר המקסימלי היחיד במערך.

קלטפלטהסבר
arr = {1,3,7,9,6,2}, n = 63arr[3] = 9
arr = {2,8,5}, n = 31arr[1] = 8
arr = {3,4,5,6,7,2}, n = 64השיא כמעט בסוף
arr = {1,5,4,3,2}, n = 51השיא כמעט בהתחלה
  • ניתן להניח כי הקלט תקין, כי n ≥ 3, וכי המערך אכן הררי.
  • אין לשנות את תוכן המערך ואין להקצות זיכרון דינמי.
  • פתרון בזמן Θ(n) אינו עומד בדרישה.
דרישות סיבוכיותזמן Θ(log n)מקום נוסף Θ(1)

שאלה 3 25 נק'

נתונה מחרוזת s באורך n המכילה אותיות אנגליות קטנות בלבד.

תת-מחרוזת של s תיקרא סיסמה חזקה אם מתקיימים כל התנאים הבאים:

  • אורכה לפחות 3;
  • היא מכילה לפחות תנועה אחת (a, e, i, o, u);
  • היא מכילה לפחות עיצור אחד (כל אות שאינה תנועה);
  • אף אות אינה מופיעה בה יותר מפעמיים.
int examT_q3(char* s);

על הפונקציה להחזיר את מספר תתי-המחרוזות של s שהן סיסמאות חזקות. תתי-מחרוזות במקומות שונים נספרות בנפרד, גם אם תוכנן זהה.

קלטפלטהסבר
s = "abcde"5—
s = "banana"8—
s = "aeiou"0אין אף עיצור
s = "aaa"0‎'a' מופיע שלוש פעמים
  • אין לשנות את תוכן המחרוזת s, אפילו לא באופן זמני.
  • ניתן להניח כי הקלט תקין וכי s אינה ריקה.
  • מערך בגודל קבוע (26 תאים) נחשב מקום Θ(1). אין להקצות זיכרון דינמי.
  • בשלד נתונה לכם פונקציית העזר is_vowel. אינכם חייבים להשתמש בה.
  • שימו לב לדרישת הזמן — כאן היא ריבועית, לא לינארית. התנאי "אף אות לא יותר מפעמיים" נשבר לתמיד ברגע שנשבר, וזה מאפשר עצירה מוקדמת.
דרישות סיבוכיותזמן O(n²)מקום נוסף O(1)

שאלה 4 25 נק' — רקורסיה

נתון מערך arr של מספרים שלמים באורך n.

רצף עולה ממש הוא קטע רציף של המערך שבו כל איבר גדול ממש מקודמו.

int examT_q4(int* arr, int n);

על הפונקציה להחזיר את אורכו של הרצף העולה ממש הארוך ביותר במערך. עבור מערך ריק יש להחזיר 0.

קלטפלטהסבר
arr = {1,3,2,4,5,6}, n = 64‎2,4,5,6
arr = {3,2,1}, n = 31אין עלייה כלל
arr = {2,2,3,4}, n = 43‎2,3,4 — שוויון אינו עלייה
arr = {4,3,2,1,2,3,4,5}, n = 85‎1,2,3,4,5
  • על הפונקציה להיות רקורסיבית בלבד, ללא שימוש בלולאות — בכל הפונקציות שתכתבו.
  • אסור להשתמש בפונקציית מעטפת — examT_q4 עצמה חייבת לקרוא לעצמה.
  • אין להקצות זיכרון דינמי ואין לשנות את תוכן המערך.
  • אין דרישות סיבוכיות בשאלה זו.

איך עובדים כאן

  • כתבו בעורך שמשמאל. שלושה קבצים, לשונית לכל שאלה. אל תשנו את main.
  • הרץ בדיקות מריץ את הפונקציה שלכם מול מקרי הבדיקה של השאלה — כולל בדיקות של האילוצים (לולאות ברקורסיה, שינוי הקלט, פונקציית מעטפת).
  • סיבוכיות אינה נבדקת אוטומטית. פתרון שעובר את כל הבדיקות בסיבוכיות שגויה — נכשל בשאלה.
  • בסיום לחצו סיום והגשה, שמרו את קובץ ההגשה, ובקשו מ-Claude ציון עם /grade.
